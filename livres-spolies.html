Chargement en cours

Comment ça marche : tapez un titre, un auteur ou une cote dans la barre de recherche pour vérifier si un ouvrage figure déjà dans le catalogue numérisé (partiellement affiché ci-dessous) — la même recherche filtre aussi le tableau des livres spoliés. Tout n'étant pas catalogué, pensez aussi aux fiches papier. Cochez Retrouvé une fois l'ouvrage localisé, Ex-libris s'il porte une marque de provenance, et notez le nom de l'ancien possesseur dès qu'il est identifié. Les modifications sont enregistrées dans ce navigateur et synchronisées automatiquement avec le reste de l'équipe (voir l'indicateur en haut de page). « Exporter le JSON » reste utile pour figer une version datée dans data/livres-spolies.json.
