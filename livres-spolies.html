Comment ça marche

Tapez un titre, un auteur ou une cote dans la barre de recherche pour vérifier si un ouvrage figure déjà dans le catalogue numérisé (résultats sous le champ) ; la même recherche filtre aussi le tableau des livres spoliés. Tout n'étant pas catalogué, pensez aussi aux fiches papier.

Pour chaque ouvrage, choisissez Retrouvé (Oui / Non) et Ex-libris s'il porte une marque de provenance. Le bouton Détails déplie l'origine, la date d'entrée, la cote BM, l'ancien possesseur (actif si ex-libris = Oui) et la date de sortie (active si l'ouvrage n'est pas retrouvé).

Les modifications sont enregistrées dans ce navigateur et synchronisées automatiquement avec le reste de l'équipe (voir l'indicateur en haut de page). « Exporter le JSON » reste utile pour figer une version datée dans data/livres-spolies.json.
