💡 Comment gérer les livres multi-pages

Pour qu'un livre apparaisse dans la visionneuse avec toutes ses pages, vous avez deux options :

  1. Colonne pages dans le CSV — ajoutez une colonne nommée pages et renseignez les noms des fichiers de pages séparés par § :
    001.jpg§002.jpg§003.jpg§…
    Ces noms seront combinés avec la valeur de la colonne num (ex. num-robaut/Boîte 1/MonLivre/001.jpg).
  2. Compléter le manifest à la main — téléchargez d'abord le manifest généré, puis ajoutez les pages des livres signalés en avertissement dans le journal. La structure attendue est :
    { "type": "book", "name": "Mon Livre", "pages": [ { "path": "num-robaut/Boîte 1/MonLivre/001.jpg" }, { "path": "num-robaut/Boîte 1/MonLivre/002.jpg" } ] }
